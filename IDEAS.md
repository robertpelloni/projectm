# IDEAS

## Aggressive Ideas & Expansions
- **WebAssembly/WebGL Port Expansion:** Build a complete PWA frontend that runs projectM directly in the browser using the Web Audio API.
- **VR/AR Integration:** Adapt the rendering engine to support stereo rendering for immersive VR music experiences.
- **Machine Learning Preset Generation:** Train a model on existing Milkdrop presets to generate entirely new, cohesive visualizations automatically.
- **Audio Reactivity 2.0:** Incorporate advanced stem separation (vocals, drums, bass) so presets can react to specific instruments rather than just overall frequency bands.
- **Language Porting:** Consider a gradual, modular rewrite of performance-critical components into Rust for memory safety and concurrency benefits.
