# VISION

## Ultimate Goal
To create the most advanced, performant, and cross-platform open-source music visualizer library (projectM), reimagining the esteemed Winamp Milkdrop experience for modern applications.

## Core Foundational Concepts
- **Universal Portability:** Seamless integration across Windows, macOS, Linux, Android, and web (Emscripten).
- **High Performance:** Leveraging modern graphics APIs to render equations and visualizations efficiently.
- **Modularity:** Maintained as a core library (libprojectM) decoupled from frontends to enable broad reuse.
- **Community-Driven:** Embracing limitless arrays of user-contributed presets and visualizations.

## User-Satisfaction Design
- Expose a simple yet powerful API for application developers.
- Maintain broad compatibility with historic preset formats (Milkdrop 1 and 2).
- Deliver mesmerizing, psychedelic visuals reacting dynamically to tempo and audio features.
